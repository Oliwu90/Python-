# Inspection Summary Report Generator

## Description
This script fetches inspection work order data from a MySQL database, processes it into summary statistics, and generates a multi-sheet Excel report.

## Structure
- `main.py`: Main script to run the report
- `data_fetcher.py`: Contains logic to connect to and fetch data from the database
- `report_generator.py`: Handles data transformation and report creation
- `requirements.txt`: Python dependencies

## Setup
```bash
pip install -r requirements.txt
```

## Run
```bash
python main.py
```

## Output
An Excel file with summary statistics saved in the current directory.
